# 台股 AI 操作指令中心 📈

台積電 + 低軌衛星 AI 供應鏈分析儀，214 支股票即時操作指令。

## 功能
- 📊 **214 支台股**：核心製造、IC設計、AI伺服器、低軌衛星、能源重電等 19 大類別
- 🤖 **AI 操作指令**：仿「週二操作指令」風格，自動判斷長線/短線/勿買
- 🔄 **每日 PM 4:00 自動更新**，或按「立即更新」手動更新
- 🔍 **搜尋**：支援股票代號、公司名稱、產業類別
- 📊 **預測準確率追蹤**：記錄每日預測，比對實際漲跌
- ☰ **產業下拉選單**：點選類別直接查看個股

## 本地開發

```bash
npm install
npm run dev
```

瀏覽器開啟 http://localhost:5173

## 部署到 Vercel（推薦）

1. Fork 或上傳此專案到 GitHub
2. 前往 [vercel.com](https://vercel.com) 匯入 GitHub repo
3. Framework 選 **Vite**，其他設定保持預設
4. 點 Deploy，完成！

之後每次更新 `src/App.jsx`，Vercel 自動重新部署。

## 更新流程

```
在 Claude 修改程式
    ↓
複製新的 App.jsx 內容
    ↓
在 GitHub 網頁編輯 src/App.jsx
    ↓
Vercel 自動部署（約 30 秒）
    ↓
所有用戶同步更新 ✅
```

## 注意事項

- 股票資料由 Claude AI 依最新知識提供，僅供參考
- **不構成投資建議**，投資有風險請審慎評估
- 預測準確率儲存於瀏覽器本機，清除快取會重置
